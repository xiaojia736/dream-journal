# 星海日记 Flutter

星海日记的 Flutter 移动端，支持 Android 和 iOS。应用默认离线运行，数据保存在本机 SQLite 与应用私有文件目录中。

## 功能

- 创建、编辑、搜索和删除生活、梦境、日记与内心记录
- 柔色线条心情图标、最多 20 字的自定义心情、标签、日期时间与每条最多五张照片
- “我的星海”随机照片墙，可换一组照片，点击照片打开对应记录
- 首页星星随机回顾过去某一天的完整记录和照片；回顾只展示记录卡与返回图标，卡片日期不显示时间；心情与标签在详情保留
- “片刻”页每日固定的鼓励寄语，31 段离线内容与网页预览同步；月亮图标为入口，主题、隐私锁、备份仅以右上角图标显示
- 深浅色主题与四位数字隐私锁
- 包含照片的 JSON 备份导入与导出

## 日常界面预览

在仓库根目录双击 `preview.cmd`，或运行 `node scripts/preview-server.mjs`，再打开 <http://127.0.0.1:4827>。轻量网页预览同步手机应用的设计，不需要 Flutter SDK 或 APK 编译；浏览器数据与手机数据独立。

当前深色样式采用“梦境浮光”：午夜紫蓝三段渐变、浅青与粉紫两团模糊流光、16 sigma 磨砂卡片与紫蓝渐变按钮。每次界面修改后先通过网页确认效果。

SQLite v2 通过新增 `custom_mood` 列保留原有记录，旧记录默认为无自定义心情。备份格式仍为 `star-sea-journal-flutter-v1`，导出增加 `customMood` 字段，导入旧备份时该字段默认为空。

## 手机端开发

以下命令用于具备 Flutter 环境的电脑。当前电脑日常修改时只做源码检查与网页预览。

```bash
flutter pub get
flutter run
```

## 最终检查和构建

只有用户确认全部效果并明确要求编译后，才构建 APK。

```bash
flutter analyze
flutter test
flutter build apk --release
```

应用标识为 `com.starsea.journal`，最低支持 Android 7.0（API 24）。
