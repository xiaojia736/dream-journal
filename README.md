# 星海日记

星海日记是一款可以离线使用的 Android/iOS 记录应用。生活点滴、梦境和心情都可以写下来，也可以直接用相册照片或拍照记录。当前手机端使用 Flutter 实现，不需要账号、电脑或服务端。

## 安装到 Android 手机

Flutter 工程位于 `flutter_app/`，应用包名为 `com.starsea.journal`。根目录保留的 `app-release.apk` 是此前构建的安装包，不代表最新源码的效果。

## 可以做什么

- 记录生活、梦境、日记和内心想法；添加发生日期、时间、情绪及标签。
- 心情使用柔色线条图标，可选择预置心情，或填写最多 20 个字符的自定义心情；详情、编辑保留展示，也能用于搜索。首页卡片只显示日期、类型、正文和照片。
- 从本地相册选图或直接拍照，每条记录最多保存 5 张照片；也能只用照片创建记录。
- 浏览、搜索、编辑和删除记录，查看回顾。
- “我的星海”随机展示记录中的照片；点照片打开对应记录，点击换图图标重新排列，没有累计或连续记录统计。
- 点击首页右上角星星，随机翻开过去某一天的完整记录和照片；回顾页只保留返回图标和记录卡，多日期时再次进入会避开刚看过的日期。
- “片刻”页显示每日固定的鼓励寄语；内置 31 段离线内容，来源见 [寄语库说明](docs/daily-quotes-sources.md)。主题、隐私锁和备份位于右上角图标，备份操作展开后显示。
- 使用深浅色外观与四位数字隐私锁。
- 导入 Flutter 版 JSON 备份，或导出包含照片的完整 JSON 备份。

记录存放在手机的应用私有空间。换手机或卸载应用前，请在“片刻 → 右上角备份图标 → 导出完整备份”保存备份；卸载可能清除本机数据。备份文件含私人文字和照片，请妥善保管。新手机安装应用后，在“片刻 → 右上角备份图标 → 导入备份”选择该文件即可合并记录；相同编号的记录会跳过。

## 先在浏览器预览

每次界面修改都同步到 `preview/`，可以先确认效果，全部满意后再编译 APK。这个预览使用轻量 HTML/CSS/JavaScript，不需要 Flutter SDK、安装依赖或编译。

Windows 双击根目录的 `preview.cmd`，或在根目录运行：

```bash
node scripts/preview-server.mjs
```

打开 <http://127.0.0.1:4827>。预览服务只监听本机；关闭命令窗口或按 `Ctrl+C` 即可停止。修改预览文件后刷新浏览器即可看到更新。

预览支持浏览记录、随机回顾、每日短句、搜索筛选、写记录、选取照片、日期心情（含自定义心情）和主题切换。示例模式与个人记录分开，个人记录保存在当前浏览器中，与手机数据独立。预览用于确认界面和交互；Android 的字体、模糊渲染、系统相册和键盘效果以最终手机测试为准。

深色界面采用“梦境浮光”：午夜紫蓝三段渐变 `#131127 → #1A1635 → #0F0D20`，左上浅青与右下粉紫两团柔光，半透明磨砂卡片、柔白选中胶囊与紫蓝渐变写入按钮。

## 开发与最终构建

日常修改只做源码与浏览器预览验证，不在这台电脑上编译 APK。以下构建步骤供最终确认后使用。

需要 Flutter 3.44 或更高版本。手机应用在 `flutter_app/`：

```bash
cd flutter_app
flutter pub get
flutter run
```

运行质量检查并构建 Android 安装包：

```bash
flutter analyze
flutter test
flutter build apk --release
```

Android 产物位于 `flutter_app/build/app/outputs/flutter-apk/`。iOS 可通过 `flutter run` 在模拟器或真机调试，并使用 Xcode 配置签名后发布。原 React Native/Expo 代码暂时保留在 `mobile/`，仅作为迁移期间的界面和功能参考。

仓库中的 `server/` 是早期本地 Node.js + SQLite 后端原型，供之后需要服务端同步时继续开发；当前 Android 应用离线保存数据，不调用它。后端可用 `cd server; npm test` 测试。
